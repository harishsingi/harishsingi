How to read the five patterns

  • Base platform: the blueprint every project inherits — land raw, validate, model, then serve.
  • CRM ingestion: Salesforce is just the example source. The SRC → PRE → SEM pattern works for any CRM.
  • Kafka streaming: a different shape entirely — events flow continuously, no daily batch to wait for.
  • Iceberg migration: Hive tables become Iceberg tables on the same S3 data, gaining snapshots and time travel.
  • ML forecasting: Gold data becomes features, features become a forecast, the forecast goes back to the business.
